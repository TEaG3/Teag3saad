هذه الخطوات لا تنفذها GitHub Actions؛ يجب إجراؤها فعلياً وتسجيل الجهاز والإصدار والتاريخ.

## Windows
- [ ] تثبيت Setup على Windows 10 x64.
- [ ] تثبيت Setup على Windows 11 x64.
- [ ] تشغيل التطبيق من قائمة ابدأ واختصار سطح المكتب.
- [ ] إغلاق التطبيق وإعادة فتحه والتحقق من بقاء السجلات المحلية.

## USB
- [ ] اختبار وحدة FAT32.
- [ ] اختبار exFAT على نظام تشغيل يدعمها.
- [ ] تشغيل اختبار الكتابة والقراءة 4 MiB والتحقق من حذف الملف المؤقت.
- [ ] فحص مجلد الألعاب وملف ul.cfg ومجلد ART.
- [ ] تنزيل صورة واحدة والتحقق من COV 140×200 وICO 64×64.
- [ ] فصل الوحدة وإعادة توصيلها وإعادة فحص الصور.

## PlayStation 2 / OPL
- [ ] تسجيل موديل PS2 ونوع محول/توصيل USB وإصدار OPL.
- [ ] تفعيل Enable Cover Art واختيار جهاز USB كمصدر.
- [ ] التحقق من ظهور غلاف PS2 الصحيح.
- [ ] اختبار PS1 بطريقة تشغيل متوافقة، وتسجيل النتيجة منفصلة.
- [ ] توثيق إعدادات OPL وأي ملاحظات أو أخطاء.
