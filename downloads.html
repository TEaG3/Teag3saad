حالة الإصدار: روابط التحميل تعمل بعد نجاح أول عملية بناء ونشر للنسختين في صفحة GitHub Releases. إذا لم يبدأ التنزيل بعد، افتح سجل البناء وتحقق من نجاح مهمة Windows EXE.

ما الذي يقدمه التطبيق؟

  • فحص ملفات ومجلدات ألعاب PS1 وPS2 والامتدادات التي يتعرف عليها الموقع.
  • مراجعة بيانات الألعاب والأغلفة وإدارة مجلد ART.
  • تحليل مكتبة الألعاب وبيانات OPL وفق الملفات المتاحة.
  • قاعدة ألعاب مركزية ثابتة مع تخزين محلي للبيانات التي يدعمها التطبيق.

بعض الميزات تعتمد على اتصال الإنترنت، مثل جلب الأغلفة من مصادرها. أما الوصول إلى وحدات التخزين فيتطلب اختيار المجلد ومنح التطبيق الصلاحية المناسبة.

متطلبات التشغيل

  • Windows 10 أو Windows 11 بنسخة 64-bit.
  • مساحة تخزين كافية للتطبيق وملفات المكتبة.
  • صلاحية الوصول إلى مجلد الألعاب أو وحدة USB عند الفحص.

تنبيه أمان وتوقيع

الملفات الحالية غير موقعة بشهادة Code Signing. قد يعرض Windows SmartScreen رسالة تحذير ناشر غير معروف. لا تتجاوز التحذير إلا إذا تأكدت من تنزيل الملف من صفحة الإصدارات الرسمية لهذا المستودع.
