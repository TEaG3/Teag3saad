مثبت Windows الرسمي

Setup EXE

مثبت اعتيادي لإضافة التطبيق إلى Windows وإتاحة تشغيله من الاختصارات.

  • معالج تثبيت وإلغاء تثبيت.
  • إنشاء اختصار لسطح المكتب وقائمة ابدأ.
  • تثبيت ضمن حساب المستخدم.
  • يتضمن ملفات التطبيق اللازمة للعمل محلياً.
تحميل Setup EXE
حالة الإصدار: لا يصبح رابط التنزيل متاحاً إلا بعد نجاح عملية البناء ونشر ملف EXE في صفحة الإصدارات. إذا لم يبدأ التنزيل، تحقق من سجل البناء.

تنبيه أمان وتوقيع

توضح صفحة الإصدار حالة توقيع Authenticode للملف المنشور. إذا كانت الحالة NotSigned، فقد يعرض Windows SmartScreen تحذير الناشر. لا تعتبر الملف موقعاً إلا عند ظهور حالة Valid في الإصدار.

متطلبات التشغيل

  • مساحة تخزين كافية للتطبيق وملفات المكتبة.
  • صلاحية الوصول إلى مجلد الألعاب أو وحدة USB عند الفحص.
