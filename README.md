# Saad PS2 Ultimate

مدير مكتبة ألعاب PlayStation 2 وملفات OPL — تطبيق ويب عربي.

## الوظائف الحالية
- فحص مجلدي DVD وCD بحثاً عن ملفات ISO.
- محاولة استخراج Game ID من بيانات ISO أو اسم الملف.
- قراءة ملف ul.cfg وفق تخطيط شائع بسجلات ثابتة 64 بايت.
- فحص مجلدي ART وICONS.
- تحميل الأغلفة المتاحة من مصادر صور عامة وحفظها داخل وحدة التخزين المختارة.
- تحويل صورة الغلاف إلى PNG للأيقونة عند دعم المتصفح لذلك.
- اختيار مجلد صور محلي وتصدير قائمة الألعاب إلى CSV.
- واجهة عربية متجاوبة ودعم PWA للتخزين المؤقت لملفات التطبيق.

## النشر
من إعدادات المستودع اختر Pages، ثم Deploy from a branch، وحدد main والمجلد الجذر.

## حدود مهمة
- اختيار المجلدات يعتمد على File System Access API، وأفضل دعم له في Chrome وEdge على الحاسوب.
- Safari وiOS لا يضمنان الوصول المباشر إلى USB.
- Android USB OTG يحتاج إلى تكامل Native منفصل؛ نسخة الويب وحدها لا تضمن الوصول إلى وحدة USB.
- يقرأ التطبيق جزءاً أولياً من ISO لاستخراج Game ID ولا يفحص سلامة صورة اللعبة كاملة.
- دعم ul.cfg مبني على تنسيق شائع ويحتاج اختبارات مع ملفات فعلية مختلفة.
- لا يحذف التطبيق الألعاب ولا ينقلها ولا يعدل ملفات ISO.
- توفر الأغلفة يعتمد على الاتصال بالإنترنت ومصادر الصور الخارجية.
- تحقق من أسماء الصور المدعومة في إصدار OPL المستخدم لديك.
- لا يتم رفع ملفات ISO إلى خادم التطبيق.

## خارطة الطريق
1. توسيع اختبارات صيغ ul.cfg وطرق تسمية OPL.
2. قاعدة بيانات محلية للبيانات الوصفية.
3. دعم أنواع صور OPL الإضافية والتحقق من أبعاد الصور.
4. نسخ احتياطي واستعادة وإدارة الأخطاء.
5. تطبيق Android أصلي للوصول إلى USB OTG.
