# Saad PS2 Ultimate

مدير عربي لفحص مكتبة ألعاب PlayStation 2 وتجهيز صور OPL على وحدة التخزين.

## الوظائف الحالية
- فحص مجلدي `DVD` و`CD` لملفات `.iso` و`.zso`.
- محاولة استخراج Game ID من بيانات ISO أو من نمط اسم الملف؛ بيانات ZSO تؤخذ من الاسم حالياً.
- قراءة سجلات `ul.cfg` ذات الحجم 64 بايت وفق بنية OPL، واستخراج Startup ID وعدد الأجزاء ونوع الوسيط.
- مطابقة ملفات USBExtreme `ul.{CRC32}.{GAME_ID}.{PART}` باستخدام Startup ID، وحساب الأجزاء الموجودة والحجم الإجمالي.
- إظهار حالة اكتمال أجزاء UL والأجزاء المتاحة في جدول المكتبة.
- فحص صور OPL داخل مجلد `ART`.
- تجهيز الغلاف الأمامي بالمقاس القياسي **140×200 بكسل (عرض×ارتفاع)** بصيغة JPEG.
- تجهيز أيقونة قرص **64×64 بكسل** بصيغة PNG، مشتقة حالياً من قص مربع من الغلاف.
- حفظ الصورتين داخل `ART` بالأسماء `GAMEID_COV.jpg` و`GAMEID_ICO.png`.
- قاعدة بيانات محلية عبر IndexedDB، ونسخ احتياطي/استعادة JSON، وتصدير CSV.

## بنية OPL للصور والألعاب
مثال لمعرّف `SLUS_203.12`:
```
USB:/
├── CD/
├── DVD/
├── ul.cfg
├── ul.{CRC32}.SLUS_203.12.00
└── ART/
    ├── SLUS_203.12_COV.jpg
    └── SLUS_203.12_ICO.png
```
تعتمد أسماء ملفات أجزاء UL على CRC لاسم اللعبة وStartup ID؛ الأداة تطابق Startup ID وتتحقق من ترقيم الأجزاء وعددها كما هو مسجل في `ul.cfg`.

## قاعدة البيانات
- قاعدة `saad-ps2-db` هي IndexedDB محلية داخل متصفح المستخدم، وفيها مخزن `games` ومفتاح `gameId`.
- تحفظ البيانات الوصفية التي يعدلها المستخدم مثل الاسم والنوع والمنطقة والسنة والتقييم والملاحظات وOPL Game ID.
- لا توجد حالياً قاعدة بيانات خادمية أو فهرس ألعاب مركزي مدمج؛ لا يتم استيراد أسماء الألعاب أو الناشرين أو تواريخ الإصدار آلياً من قاعدة PS2 عالمية.
- النسخة الاحتياطية JSON تشمل السجلات الإضافية فقط، ولا تشمل ملفات ISO/ZSO/UL أو الصور أو محتويات وحدة USB.

## حدود التوافق والاختبار
- تطبيق الويب لا يهيئ وحدة التخزين ولا يحول ملفات الألعاب ولا ينقلها أو يحذفها.
- ملفات الألعاب لا تُرفع إلى خادم التطبيق.
- استخراج Game ID من ISO يعتمد على البحث في أول 8MB، وليس تحققاً كاملاً من صورة اللعبة.
- لا يفك التطبيق ضغط ZSO؛ إذا لم يحتوِ اسم الملف على Game ID فقد يلزم إدخاله يدوياً.
- لا يفحص التطبيق نوع نظام الملفات FAT32/exFAT أو جدول التقسيم أو التجزئة، ولا يضمن قابلية تشغيل كل لعبة.
- اختيار المجلدات يعتمد على File System Access API؛ أفضل دعم له في Chrome وEdge على الحاسوب. Safari وiOS لا يضمنان الوصول المباشر إلى USB.
- يجب تفعيل Enable cover art واختيار مصدر الألعاب من إعدادات OPL لكي تظهر الصور.
