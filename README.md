# Saad PS2 Ultimate

مدير عربي لفحص مكتبة ألعاب PlayStation 2 وتجهيز صور OPL على وحدة التخزين.

## الوظائف الحالية
- فحص مجلدي `DVD` و`CD` لملفات `.iso` و`.zso`.
- محاولة استخراج Game ID من بيانات ISO أو من نمط اسم الملف؛ بيانات ZSO تؤخذ من الاسم حالياً.
- قراءة سجلات `ul.cfg` ذات الحجم 64 بايت وفق بنية OPL، واستخراج Startup ID وعدد الأجزاء ونوع الوسيط.
- مطابقة ملفات USBExtreme `ul.{CRC32}.{GAME_ID}.{PART}` باستخدام Startup ID، وحساب الأجزاء الموجودة والحجم الإجمالي.
- إظهار حالة اكتمال أجزاء UL والأجزاء المتاحة في جدول المكتبة.
- فحص صور OPL داخل مجلد `ART`.
- تجهيز الغلاف الأمامي بالمقاس القياسي **140×200 بكسل (عرض×ارتفاع)** بصيغة JPEG.
- تجهيز أيقونة قرص **64×64 بكسل** بصيغة PNG، مشتقة حالياً من قص مربع من الغلاف.
- حفظ الصورتين داخل `ART` بالأسماء `GAMEID_COV.jpg` و`GAMEID_ICO.png`.
- قاعدة بيانات محلية عبر IndexedDB، ونسخ احتياطي/استعادة JSON، وتصدير CSV.

## بنية OPL للصور والألعاب
مثال لمعرّف `SLUS_203.12`:
```
USB:/
├── CD/
├── DVD/
├── ul.cfg
├── ul.{CRC32}.SLUS_203.12.00
└── ART/
    ├── SLUS_203.12_COV.jpg
    └── SLUS_203.12_ICO.png
```
تعتمد أسماء ملفات أجزاء UL على CRC لاسم اللعبة وStartup ID؛ الأداة تطابق Startup ID وتتحقق من ترقيم الأجزاء وعددها كما هو مسجل في `ul.cfg`.

## قاعدة البيانات
- قاعدة `saad-ps2-db` هي IndexedDB محلية داخل متصفح المستخدم، وفيها مخزن `games` ومفتاح `gameId`.
- تحفظ البيانات الوصفية التي يعدلها المستخدم مثل الاسم والنوع والمنطقة والسنة والتقييم والملاحظات وOPL Game ID.
- يوجد كتالوج مركزي عام ثابت في `data/game-catalog.json` تتم مزامنته وتخزين نسخة منه محلياً؛ لا توجد قاعدة بيانات خادمية قابلة للكتابة من الزوار ولا يتم اختلاق بيانات الألعاب.
- النسخة الاحتياطية JSON تشمل السجلات الإضافية فقط، ولا تشمل ملفات ISO/ZSO/UL أو الصور أو محتويات وحدة USB.

## حدود التوافق والاختبار
- تطبيق الويب لا يهيئ وحدة التخزين ولا يحول ملفات الألعاب ولا ينقلها أو يحذفها.
- ملفات الألعاب لا تُرفع إلى خادم التطبيق.
- استخراج Game ID من ISO يعتمد على البحث في أول 8MB، وليس تحققاً كاملاً من صورة اللعبة.
- لا يفك التطبيق ضغط ZSO؛ إذا لم يحتوِ اسم الملف على Game ID فقد يلزم إدخاله يدوياً.
- لا يفحص التطبيق نوع نظام الملفات FAT32/exFAT أو جدول التقسيم أو التجزئة، ولا يضمن قابلية تشغيل كل لعبة.
- اختيار المجلدات يعتمد على File System Access API؛ أفضل دعم له في Chrome وEdge على الحاسوب. Safari وiOS لا يضمنان الوصول المباشر إلى USB.
- يجب تفعيل Enable cover art واختيار مصدر الألعاب من إعدادات OPL لكي تظهر الصور.

## النشر
يُنشر الموقع بواسطة GitHub Actions من الفرع `main`. راجع تبويب Actions للتأكد من نجاح آخر عملية نشر.


## تدقيق قاعدة الألعاب والتخزين (v1.2)
- أضيف محرك محلي مستقل للتحقق من Game ID، وتصنيف المنطقة استدلالياً من بادئة المعرّف، واكتشاف تكرار المعرفات ومصادر الملفات وألعاب UL غير المكتملة.
- أضيف فحص فعلي لملفات مجلد ART: سلامة الصورة وأبعاد الغلاف 140×200 والأيقونة 64×64.
- أضيف فحص إمكانات المتصفح وصلاحية الكتابة، ويطلب الموقع إذن read/write قبل حفظ الأغلفة.
- لا يُنشئ المحرك أسماء ألعاب أو مناطق مؤكدة من تخمين؛ بادئات المنطقة مؤشرات وليست بديلاً عن قاعدة بيانات موثقة لكل عنوان.

## أنظمة ملفات وحدات USB (FAT32 / exFAT / NTFS / ext وغيرها)
الموقع لا يحتوي على مشغلات أنظمة ملفات ولا يستطيع تهيئة الفلاش أو قراءة القرص الخام. عند توصيل الفلاش وظهوره كوحدة تخزين مركّبة في نظام التشغيل، يستطيع متصفح متوافق استخدام منتقي المجلدات للقراءة والكتابة على المجلدات التي يمنحها المستخدم الإذن. هذا يخص قدرة نظام التشغيل والمتصفح على فتح الوحدة، ولا يعني أن OPL نفسه يستطيع تشغيل الألعاب من أي نظام ملفات. وفق وثائق OPL الحالية، يدعم USB/MX4SIO نظام FAT32، كما أضيف exFAT في إصدارات OPL 1.2.0 beta؛ أما إصدارات OPL الأقدم فتحتاج FAT32. لا تضع NTFS أو APFS أو ext ضمن خيارات فلاش OPL.
- Chrome/Edge على سطح مكتب يدعم واجهة اختيار المجلدات والكتابة المباشرة عند استخدام HTTPS، لأي نظام ملفات مركّب ومدعوم من نظام التشغيل المضيف.
- Safari على iPad/iPhone لا يتيح للموقع وصولاً عاماً مضموناً للقراءة والكتابة على USB؛ يلزم تطبيق أصلي/تكامل Capacitor مع Android Storage Access Framework أو واجهة نظام مناسبة.
- لا يتم تعديل تقسيم الفلاش أو نظام الملفات، ولا حذف أو نقل ملفات الألعاب. الكتابة الحالية مخصصة لملفات صور ART التي ينشئها المستخدم من داخل الموقع.
- صيغة ISO/ZSO/UL هي صيغ محتوى ألعاب وليست أنظمة ملفات USB. يدعم الفهرس ISO وZSO وملفات UL في مجلد OPL، ولا يعني ذلك فك ضغط ZSO أو تحويل ملفات الألعاب.


## دعم أغلفة ألعاب PS1
- يقبل حقل معرّف اللعبة الرقم التسلسلي لألعاب PS1 بصيغة `SLUS-00896` أو `SLES-02080` إلى جانب معرّفات PS2 المعتادة.
- عند إدخال معرّف PS1 في تفاصيل اللعبة، يستخدم الموقع مجموعة أغلفة PSX من `xlenore/psx-covers` عبر النمط `covers/default/{serial}.jpg`، ويحتفظ باسم المعرّف بصيغة الشرطة `SLUS-00896`.
- يظل مصدر أغلفة PS2 منفصلاً ولا يتغير. يتطلب تنزيل الصور اتصالاً بالإنترنت وصلاحية الكتابة إلى مجلد `ART`.
- يدعم الفاحص قراءة أسماء وملفات PS1 المعروفة ضمن الامتدادات المدعومة ومحاولة استخراج الرقم التسلسلي، لكن لا يحول الملفات ولا يشغّلها. الملفات التي لا تحمل معرّفاً صالحاً تبقى بحاجة إلى تحقق يدوي.


## الفحص التلقائي الشامل PS1 وPS2 (v1.3)
- يفحص المجلد المختار ومجلداته الفرعية، مع تخطي مجلد ART.
- يتعرف على امتدادات ISO وZSO وUL وVCD وBIN وCUE وIMG وCHD وPBP. لا يُستخدم الامتداد وحده لتخمين أن BIN/CUE/CHD/PBP/VCD تخص PS1؛ يعتمد التصنيف المؤكد على Serial ID، وإلا تعرض المنصة UNKNOWN.
- يحاول استخراج الرقم التسلسلي من اسم الملف أو محتوى CUE/القرص؛ قد تبقى بعض صور CHD/PBP أو الصور غير القياسية بلا معرّف تلقائي وتحتاج إدخال الرقم من تفاصيل اللعبة.
- بعد الفحص يبدأ تنزيل الأغلفة والأيقونات الناقصة تلقائياً إلى ART. يلزم الاتصال بالإنترنت وإبقاء الصفحة مفتوحة ومنح إذن الكتابة.
- FAT وFAT32 وexFAT تعتمد على دعم نظام التشغيل للوحدة؛ لا يقرأ الموقع نوع نظام الملفات ولا يهيئ الفلاش ولا يغير تقسيمه.
- الكتابة المباشرة تتطلب متصفح Chromium على سطح المكتب يدعم File System Access API وHTTPS. Firefox وSafari وiPad وInternet Explorer لا توفر نفس صلاحية الوصول المباشر؛ اختيار الملفات فيها للقراءة فقط.


## دعم ملفات PS1-VCD
- تمت إضافة امتداد `.vcd` إلى الفحص التلقائي للمجلدات والملفات المختارة، ويصنّف كملف PS1.
- يحاول الموقع استخراج الرقم التسلسلي من اسم ملف VCD أو من بياناته الثنائية ضمن أول 32MB؛ إذا لم يجده، يعرض الملف في المكتبة بمعرّف محلي ولا يستطيع جلب غلاف موثوق تلقائياً حتى يُدخل الرقم التسلسلي الصحيح.
- هذا دعم للفهرسة والتعرّف وجلب الأغلفة عند توفر Serial ID، وليس محوّلاً لصيغة VCD أو مشغّلاً لها. توافق VCD مع POPStarter/OPL يعتمد على طريقة إعداد الملف والجهاز.


## قاعدة الألعاب المركزية والعمل دون إنترنت

- ملف الكتالوج المركزي: `data/game-catalog.json`، ويُقرأ كقاعدة بيانات عامة مشتركة للزوار. لا يسمح GitHub Pages للمتصفح بتعديل هذا الملف مباشرة؛ تحديث سجلاته يتم عبر تغييرات المستودع.
- تُخزّن نسخة الكتالوج التي تم تحميلها بنجاح في IndexedDB محلياً، ويستخدمها الموقع عند انقطاع الإنترنت.
- مخزن قاعدة البيانات المحلي `saad-ps2-db` أصبح بالإصدار 3 ويحتوي على سجلات الألعاب والمكتبة ونسخة الكتالوج.
- يدعم الفهرس امتدادات ISO وZSO وملفات OPL UL وVCD وBIN وCUE وIMG وCHD وPBP. قد يحتاج بعض ملفات الصور إلى إدخال Game ID يدوياً إذا لم يمكن استخراج الرقم التسلسلي.
- FAT وFAT32 وexFAT أنظمة ملفات لوحدات التخزين وليست صيغ ألعاب. يقرأ الموقع الملفات التي يتيحها نظام التشغيل والمتصفح؛ ولا يقوم بتهيئة الفلاش أو تغيير نظام الملفات.
- دعم قراءة الملفات لا يعني أن كل إصدار من OPL يستطيع تشغيل كل صيغة أو نظام ملفات. تحقق من توافق إصدار OPL والجهاز قبل الاستخدام.
- يُملأ الكتالوج تلقائياً من ملفات العناوين المنشورة في مشروعي GameDB-PSX وGameDB-PS2، ويحتفظ بالمنصة والرقم التسلسلي واسم اللعبة ومصدر الإصدار. لا تُضاف سنوات أو ناشرون أو أنواع ما لم تتوفر في البيانات المصدرية.


## تطبيق Windows (EXE) — الإصدار 1.1.0
- يوجد تطبيق سطح مكتب مستقل مبني على Electron ويستخدم واجهة الموقع نفسها.
- ينتج GitHub Actions ملف Setup واحداً لويندوز 10/11 x64، ولا ينتج إصدار Portable.
- يستخدم Electron 45.2.3 وelectron-builder 26.18.1، مع ملف قفل npm و`npm ci` وتدقيق `npm audit`.
- يشغّل البناء اختبار بدء تشغيل Electron آلياً قبل إنشاء المُثبّت.
- يمكن تفعيل توقيع Authenticode عند توفير شهادة ناشر PFX عبر أسرار المستودع `WINDOWS_CERTIFICATE_BASE64` و`WINDOWS_CERTIFICATE_PASSWORD`. لا ترفع ملف الشهادة أو كلمة مرورها إلى المستودع.
- إذا لم تتوفر شهادة ناشر صالحة فسيبقى الملف غير موقع، ويعرض سجل الإصدار الحالة الفعلية للتوقيع.
- اختبار USB/PS2 الحقيقي منفصل عن اختبار CI، ويجب تسجيله وفق `docs/HARDWARE-QA.md`.

## مصادر قاعدة بيانات الألعاب المركزية
يراجع `data/THIRD-PARTY-NOTICES.md` مصادر بيانات PS1/PS2 وشروطها. تتم المزامنة أسبوعياً وعند نشر التغييرات بواسطة `scripts/update-game-catalog.cjs`. يحتفظ الموقع بنسخة الكتالوج في IndexedDB للعمل دون اتصال.

## اختبار الأجهزة
اختبار بدء تطبيق Electron في Windows CI لا يعوض اختبار USB أو جهاز PS2. استخدم `docs/HARDWARE-QA.md` لتوثيق التجربة الفعلية؛ لا تُسجل النتائج على أنها ناجحة قبل تنفيذها.
