# Saad PS2 Ultimate

مدير عربي لفحص مكتبة ألعاب PlayStation 2 وتجهيز صور OPL على وحدة التخزين.

## وظائف التطبيق
- فحص مجلدي `DVD` و`CD` لملفات `.iso` و`.zso`.
- محاولة استخراج Game ID من بيانات ISO أو من نمط اسم الملف.
- قراءة سجلات `ul.cfg` ذات الحجم الثابت 64 بايت وعرض معلومات ألعاب UL.
- تعيين Game ID يدوياً عند عدم توفره في بيانات اللعبة.
- فحص صور OPL داخل مجلد `ART`.
- تجهيز الغلاف الأمامي بالمقاس القياسي **140×200 بكسل (عرض×ارتفاع)** بصيغة JPEG.
- تجهيز أيقونة قرص مربعة **64×64 بكسل** بصيغة PNG.
- حفظ الغلاف والأيقونة معاً داخل `ART` بالأسماء `GAMEID_COV.jpg` و`GAMEID_ICO.png`.
- قاعدة بيانات محلية عبر IndexedDB، ونسخ احتياطي/استعادة JSON، وتصدير CSV.

## بنية OPL للصور
مثال للعبة ذات المعرّف `SLUS_203.12`:
```
USB:/
└── ART/
    ├── SLUS_203.12_COV.jpg
    └── SLUS_203.12_ICO.png
```
يجب تفعيل **Enable Cover Art** من إعدادات عرض OPL، والتأكد من اختيار جهاز التخزين المستخدم ضمن إعدادات OPL.

## حدود التوافق
- تطبيق الويب لا يهيئ وحدة التخزين ولا يحول ملفات الألعاب ولا ينقلها أو يحذفها.
- ملفات ISO لا تُرفع إلى خادم التطبيق.
- قراءة Game ID من ISO تعتمد على البحث داخل أول 8MB، وليست فحصاً كاملاً لسلامة ملف اللعبة.
- ملفات ZSO يتم اكتشافها، لكن التطبيق لا يفك ضغطها؛ وقد يلزم تعيين Game ID يدوياً.
- قراءة `ul.cfg` تستخدم تنسيق USBExtreme الشائع بسجلات 64 بايت، ويجب مراجعة معرّفات ألعاب UL يدوياً قبل حفظ صورها.
- توافق ملفات الألعاب ونظام الملفات يعتمد على إصدار OPL والجهاز. التطبيق لا يتحقق من قابلية تشغيل اللعبة على جهاز PS2.
- اختيار المجلدات يعتمد على File System Access API؛ أفضل دعم له في Chrome وEdge على الحاسوب. Safari وiOS لا يضمنان الوصول المباشر إلى USB.

## النشر
يُنشر الموقع بواسطة GitHub Actions من الفرع `main`. راجع تبويب Actions للتأكد من نجاح آخر عملية نشر.
